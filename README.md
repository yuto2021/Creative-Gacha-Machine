Creative Gacha Machine
A highly customizable gacha machine mod for Minecraft.

Features
Group Library
Multiple Gacha Groups
Add / Edit / Delete / Duplicate Groups
Multiple Reward Pages
Weight-based Reward System
Payment System
Gacha Tickets
English Localization
Japanese Localization
Supported Versions
Minecraft 1.20.1
Fabric
Forge
Installation
Install Fabric or Forge for Minecraft 1.20.1.
Place Creative Gacha Machine into your mods folder.
Launch the game.
